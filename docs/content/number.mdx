### Increment

```ts tab='Shape'
type Increment<N extends number, C extends number = 1>
```

```ts tab='Source'
type Increment<N extends number, C extends number = 1> = (
	IsNegative<C> extends true
		? _Decrement<Stringify<N>, Abs<Stringify<C>>>
		: _Increment<Stringify<N>, Stringify<C>>
) extends infer R extends string
	? ToNumber<R>
	: never;
```

Increments a number by a given amount.

```ts title='Example'
type R1 = Increment<1>; // 2
type R2 = Increment<1, 2>; // 3
type R3 = Increment<1, -1>; // 0
type R4 = Increment<-1, 1>; // 0
type R5 = Increment<-1, -1>; // -2
```

## utils

### ToNumber

```ts tab='Shape'
type ToNumber<T extends string>
```

```ts tab='Source'
type ToNumber<T extends string> = T extends `${infer N extends number}` ? N : never;
```

Converts a number in string form to its number representation.

```ts title='Example'
type R1 = ToNumber<"123">; // 123
```
