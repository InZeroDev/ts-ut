## extract

### ExtractIfStartsWith

```ts tab='Shape'
type ExtractIfStartsWith<T extends string, P extends string>
```

```ts tab='Source'
type ExtractIfStartsWith<T extends string, P extends string> = T extends `${P}${string}`
	? T
	: never;
```

Extracts from a union of strings those that start with a given prefix.

```ts title='Example'
type Keys = KeyofDeep<Config>; // 'defaults.a' | 'defaults.b' | 'messages.error' | 'messages.success'
type R1 = ExtractIfStartsWith<Keys, 'defaults'>; // 'defaults.a' | 'defaults.b'
type R2 = ExtractIfStartsWith<Keys, 'messages'>; // 'messages.error' | 'messages.success'
```

	: never;

### LastChar

```ts tab='Shape'
type LastChar<T extends string>
```

```ts tab='Source'
type LastChar<T extends string> = T extends `${string}${infer U extends string}`
	? U extends ""
		? T
		: LastChar<U>
	: never;
```

Returns the last character in a given string.

<Callout type='info'>

This type will run `T["length"]` times to reach the last character.

</Callout>

## split

### Split

```ts tab='Shape'
type Split<T extends string, S extends string>
```

```ts tab='Source'
type Split<T extends string, S extends string> = T extends ""
	? []
	: T extends `${infer L}${S}${infer R}`
		? [L, ...Split<R, S>]
		: [T];
```

### Join

```ts tab='Shape'
type Join<T extends ROList<string>, S extends string = "">
```

```ts tab='Source'
type Join<T extends ROList<string>, S extends string = ""> = T extends readonly [
	infer F extends string,
	...infer R extends ROList<string>,
]
	? R["length"] extends 0
		? F
		: `${F}${S}${Join<R, S>}`
	: "";
```

### Stringable

type Stringable

```ts tab='Source'
type Stringable = string | number | boolean | bigint | null | undefined;
```

A type that represents values that can be converted to strings.

### Suggest

```ts tab='Shape'
type Suggest<T>
```

```ts tab='Source'
type Suggest<T> = Extract<T, string> | (string & {});
```

Generates a type that suggests a pre-defined list of choices while accepting any other string.

```ts title='Example'
type Fruit = Suggest<"Apple" | "Orange">;

const f1: Fruit = "Apple"; // Valid + Auto-completion
const f2: Fruit = "Banana"; // Valid
```

### Stringify

```ts tab='Shape'
type Stringify<T>
```

```ts tab='Source'
type Stringify<T> = T extends Stringable ? `${T}` : never;
```

Converts a [Stringable](#stringable) to its string representation.

```ts title='Example'
type R1 = Stringify<123>; // "123"
type R2 = Stringify<{ a: 1 }>; // never
```
