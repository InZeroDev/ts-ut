## extract

### ExtractByValue

```ts tab='Shape'
type ExtractByValue<T, M extends Partial<Dict<Keys<T>>>>
```

```ts tab='Source'
type ExtractByValue<T, M extends Partial<Dict<Keys<T>>>> = T extends T
	? Values<{
			[P in keyof M]: P extends keyof T ? HasType<T[P], M[P]> : false;
		}> extends true
		? T
		: never
	: never;
```

Extracts union members whose specified properties contain at least one of the specified value types.

```ts title='Example'
type Obj = { a: string } | { a: number | boolean } | { a: null };

type R1 = Extract<Obj, { a: string | number }>; // { a: string }
type R2 = ExtractByValue<Obj, { a: string | number }>; // { a: string } | { a: number | boolean }
```

### ExtractByExactValue

```ts tab='Shape'
type ExtractByExactValue<T, M extends Partial<Dict<Keys<T>>>>
```

```ts tab='Source'
type ExtractByExactValue<T, M extends Partial<Dict<Keys<T>>>> = T extends T
	? Values<{
			[P in keyof M]: P extends keyof T ? AreEqual<T[P], M[P]> : false;
		}> extends true
		? T
		: never
	: never;
```

Extracts union members whose specified properties exactly match the specified value types.

```ts title='Example'
type Obj = { a: string } | { a: string | boolean } | { a: null };

type R1 = Extract<Obj, { a: string | boolean }>; // { a: string } | { a: string | boolean }
type R2 = ExtractByExactValue<Obj, { a: string | boolean }>; // { a: string | boolean }
```

### Get

```ts tab='Shape'
type Get<T, K extends SuggestKey<Keys<Known<T>>>>
```

```ts tab='Source'
type Get<T, K extends SuggestKey<Keys<Known<T>>>> = T extends T
	? K extends keyof T
		? T[K]
		: never
	: never;
```

An alias for `Obj['Key']`.

```ts title='Example'
type R1 = Get<{ a: 1, b: 2 }, 'a'>; // 1
```

### Set

```ts tab='Shape'
type Set<T, K extends SuggestKey<Keys<Known<T>>>, V>
```

```ts tab='Source'
type Set<T, K extends SuggestKey<Keys<Known<T>>>, V> = T extends T
	? Prettify<{ [P in K]: V } & { [P in keyof T]: P extends K ? V : T[P] }>
	: never;
```

Set a value in an object.

```ts title='Example'
type R1 = Set<{ readonly c?: 1 }, 'c', 4>; // { readonly c?: 4 }

type R2 = Set<{ a: 1 }, 'b', 2>; // { a: 1, b: 2 }
```

<Callout type='info'>

If the key doesn't exist, it will be added.

</Callout>

### GetDeep

```ts tab='Shape'
type GetDeep<
	T,
	K extends SuggestKey<KeysDeep<Known<T>>, true>,
	O extends boolean = false,
>
```

```ts tab='Source'
type GetDeep<
	T,
	K extends SuggestKey<KeysDeep<Known<T>>, true>,
	O extends boolean = false,
> = T extends T
	? K extends K
		? Next<K> extends [infer N extends string, infer R]
			? _GetDeep<T, N, R, O>
			: never
		: never
	: never;
```

Get a deeply nested value using dot-notation.

```ts title='Example'
type Obj = { a: { b?: { c: 1 } } };

type R1 = GetDeep<Obj, 'a.b.c'>; // 1
type R2 = GetDeep<Obj, 'a.b.c', true>; // 1 | undefined
```

<Callout type='info'>

Set `O` to `true` to preserve `undefined` if one of the parents is optional.

</Callout>

### SetDeep

```ts tab='Shape'
type SetDeep<T, K extends SuggestKey<KeysDeep<Known<T>>, true>, V>
```

```ts tab='Source'
type SetDeep<T, K extends SuggestKey<KeysDeep<Known<T>>, true>, V> = T extends T
	? K extends K
		? Next<K> extends [infer N extends string, infer R]
			? Prettify<_SetDeep<Merge<{ [P in N]: IsNever<R> extends true ? V : {} }, T>, N, R, V>>
			: never
		: never
	: never;
```

Set a deeply nested value using dot-notation.

```ts title='Example'
type R1 = SetDeep<{ a: { b: { c: 1 } } }, 'a.b.c', 4>; // { a: { b: { c: 4 } } }

type R2 = SetDeep<{}, 'a.b.c', 4>; // { a: { b: { c: 4 } } }
type R3 = SetDeep<{ a: boolean }, 'a.b.c', 4>; // { a: boolean }
```

<Callout type='info'>

- If a parent key doesn't exist, it will be created as an empty object.
- If a parent key is not an object type, it won't be modified.

</Callout>

### KeysDeep

```ts tab='Shape'
type KeysDeep<
	T,
	R extends "leaf" | "parent" | "both" = "both",
	_K extends string = "",
>
```

```ts tab='Source'
type KeysDeep<
	T,
	R extends "leaf" | "parent" | "both" = "both",
	_K extends string = "",
> = T extends T
	? Values<{
			[P in keyof T as P extends string | number ? P : never]-?: T[P] extends infer TP
				? Next<P & (string | number), _K> extends infer N extends string
					? TP extends Dict
						? (R extends "leaf" ? never : N) | KeysDeep<TP, R, N>
						: R extends "parent"
							? never
							: N
					: never
				: never;
		}>
	: never;
```

A deep version of [Keys](#keys).

```ts title='Example'
type Config = { foo: string, bar: { baz: number } };

type R1 = KeysDeep<Config> // "foo" | "bar" | "bar.baz"
type R2 = KeysDeep<Config, "leaf"> // "foo" | "bar.baz"
type R3 = KeysDeep<Config, "parent"> // "bar"
```

<Callout type='info'>

`R` controls whether to return leaf keys, parent keys, or both (default).

</Callout>

## merge

### MergeUnion

```ts tab='Shape'
type MergeUnion<A, B, P extends boolean = false>
```

```ts tab='Source'
type MergeUnion<A, B, P extends boolean = false> = A extends A
	? B extends B
		? Prettify<P extends true ? _MergeUnionPreserve<A, B> : _MergeUnion<A, B>>
		: never
	: never;
```

Merge two objects, keeping all keys from both. On conflict, `B` wins.

```ts title='Example'
type A = { readonly a: 1, b: 2 };
type B = { a: "<>", c: 4 };

type AB1 = MergeUnion<A, B>; // { a: "<>", b: 2, c: 4 }
type AB2 = MergeUnion<A, B, true>; // { readonly a: "<>", b: 2, c: 4 }
```

<Callout type='info'>

Set `P` to true to use `A`'s modifiers.

</Callout>

### MergeUnionDeep

```ts tab='Shape'
type MergeUnionDeep<A, B, P extends boolean = false>
```

```ts tab='Source'
type MergeUnionDeep<A, B, P extends boolean = false> = A extends A
	? B extends B
		? PrettifyDeep<P extends true ? _MergeUnionDeepPreserve<A, B> : _MergeUnionDeep<A, B>>
		: never
	: never;
```

Merge two objects deeply, keeping all keys from both. On conflict, values are recursively merged if both are objects, otherwise `B` wins.

```ts title='Example'
type A = { readonly a: 1, b: { c: 1, d: "b" } };
type B = { a: 99, b: { c: 4 } };

type AB1 = MergeUnion<A, B>; // { a: 99, b: { c: 4 } }
type AB2 = MergeUnionDeep<A, B>; // { a: 99, b: { c: 4, d: "b" } }
```

<Callout type='info'>

- Set `P` to true to use `A`'s modifiers.
- Non-object members of `A` are discarded while those of `B` are preserved.

</Callout>


```ts tab='Source'
type MergeDiff<A, B> = A extends A

		? {

			}

	: never;
```


### MergeDiffDeep

```ts tab='Shape'
type MergeDiffDeep<A, B>
```

```ts tab='Source'
type MergeDiffDeep<A, B> = A extends A
	? B extends B
		? {
				[
					P in keyof A as P extends keyof B ? (HasType<B[P], Dict> extends true ? P : never) : P
				]: P extends keyof B
					? HasType<B[P], Dict> | HasType<A[P], Dict> extends true
						? MergeDiffDeep<A[P], B[P]>
						: A[P]
					: A[P];
			}
		: never
	: never;
```

Merge two objects deeply, keeping all keys that exist only in `A` and recursively merging keys that exist in both when both values are objects.

```ts title='Example'
type A = { a: 1, b: { c: 1, d: "b" } };
type B = { b: { d: "b" } };

type AB1 = MergeDiff<A, B>; // { a: 1 }
type AB2 = MergeDiffDeep<A, B>; // { a: 1, b: { c: 1 } }
```
