## Get



## Keyof

```ts
type Keyof<T> = ...
```

Similar to `keyof Obj`, except it returns all possible keys when `T` is a union and only known keys when `T` has `[x: string]: unknown` keys.

```ts title='Example'
type Config = { foo: string, bar: number, [x: string]: unknown } | { c: 4 };

type R1 = Keyof<Config>; // 'foo' | 'bar' | 'c'
```

## Valueof

```ts
type Valueof<T> = ...
```

Similar to `Obj[keyof Obj]`, except it returns all possible values when `T` is a union and only known keys' values when `T` has `[x: string]: unknown` keys.

```ts title='Example'
type Config = { foo: string, bar: boolean, [x: string]: unknown } | { c: 4 };

type R1 = Valueof<Config>; // string | boolean | 4
```

## MergeUnion

```ts
type MergeUnion<A, B, P> = ...
```

Merge two objects by keeping all keys from `A` and `B`, on conflict, `B` wins.

```ts title='Example'
type A = { readonly a: 1, b: 2 };
type B = { a: "<>", c: 4 };

type AB1 = MergeUnion<A, B>; // { a: "<>", b: 2, c: 4 }
type AB2 = MergeUnion<A, B, true>; // { readonly a: "<>", b: 2, c: 4 }
```

<Callout type='info'>

If `P` is `true`, then on conflict `B` wins but `A`'s shape is used.

</Callout>

## MergeInt

```ts
type MergeInt<A, B, P> = ...
```

Merge two objects by keeping all keys from `A` that exist in `B`, values are taken from `B`.

```ts title='Example'
type A = { readonly a: 1, b: 2 };
type B = { a: "<>", c: 4 };

type AB1 = MergeInt<A, B>; // { a: "<>" }
type AB2 = MergeInt<A, B, true>; // { readonly a: "<>" }
```

<Callout type='info'>

If `P` is `true`, then values will be taken from 'B', but `A`'s shape will be used.

</Callout>

## MergeDiff

```ts
type MergeDiff<A, B> = ...
```

Merge two objects by keeping all keys from `A` that `B` lacks.

```ts title='Example'
type A = { readonly a: 1, b: 2 };
type B = { a: "<>", c: 4 };

type AB = MergeDiff<A, B>; // { b: 2 }
type BA = MergeDiff<B, A>; // { c: 4 }
```

## MergeSymDiff

```ts
type MergeSymDiff<A, B> = ...
```

Merge two objects by keeping all non-shared keys from both `A` and `B`.

```ts title='Example'
type A = { readonly a: 1, b: 2 };
type B = { a: "<>", c: 4 };

type AB = MergeSymDiff<A, B>; // { b: 2, c: 4 }
type BA = AB;
```

## LoosePick

```ts
type LoosePick<T, K> = ...
```

Similar to the built-in [Pick](https://www.typescriptlang.org/docs/handbook/utility-types.html#picktype-keys) type, except it lets you pass any keys
and it will only pick the keys that actually exist in `T`.

```ts title='Example'
type R1 = Pick<{a: 1}, "a" | "b">; // { a: 1, b: unknown }
type R2 = LoosePick<{a: 1}, "a" | "b">; // { a: 1 }
```

## StrictPick

```ts
type StrictPick<T, K> = ...
```

Similar to the built-in [Pick](https://www.typescriptlang.org/docs/handbook/utility-types.html#picktype-keys) type, except it works differently when `T` is a union of objects.

```ts title='Example'
type R1 = Pick<{a: 1} | {b: 2}, "a">; // { a: unknown } // + Error
type R2 = StrictPick<{a: 1} | {b: 2}, "a">; // { a: 1 } | {}
```

## LooseOmit

```ts
type LooseOmit<T, K> = ...
```

Similar to the built-in [Omit](https://www.typescriptlang.org/docs/handbook/utility-types.html#omittype-keys) type, except it suggests possible keys
and it works differently when `T` is a union of objects.

```ts title='Example'
type R1 = Omit<{a: 1, b: 2}, "a">; // { b: 2 }
type R2 = LooseOmit<{a: 1, b: 2}, "a">; // { b: 2 } // + Auto-completion for 'a'

type R3 = Omit<{a: 1} | {b: 2}, "a">; // {}
type R4 = LooseOmit<{a: 1} | {b: 2}, "a">; // {} | {b: 2}
```

## StrictOmit

```ts
type StrictOmit<T, K> = ...
```

Similar to the built-in [Omit](https://www.typescriptlang.org/docs/handbook/utility-types.html#omittype-keys) type, except it enforces passing an existing key
and it works differently when `T` is a union of objects.

```ts title='Example'
type R1 = Omit<{a: 1}, "z">; // {a: 1}
type R2 = StrictOmit<{a: 1}, "z">; // {a: 1} // + Error saying 'z' is not an existing key

type R3 = Omit<{a: 1} | {b: 2}, "a">; // {} // + Error
type R4 = StrictOmit<{a: 1} | {b: 2}, "a">; // {} | {b: 2}
```

## Known

```ts
type Known<T> = ...
```

Removes `[x: string]: unknown` from an object.

```ts title='Example'
type Config = { foo: string, bar: boolean, [x: string]: string };
type KnownConfig = Known<Config>; // { foo: string, bar: boolean }

// Can also be used on tuples to get the guaranteed elements
type R = Known<[string, number?, ...number[]]>; // [string]
```
