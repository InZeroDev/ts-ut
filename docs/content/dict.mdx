## extract

### ExtractByValue

```ts
type ExtractByValue<T, M> = ...
```

Extracts union members whose specified properties contain at least one of the specified value types.

```ts title='Example'
type Obj = { a: string } | { a: number | boolean } | { a: null };

type R1 = Extract<Obj, { a: string | number }>; // { a: string }
type R2 = ExtractByValue<Obj, { a: string | number }>; // { a: string } | { a: number | boolean }
```

### ExtractByExactValue

```ts
type ExtractByExactValue<T, M> = ...
```

Extracts union members whose specified properties exactly match the specified value types.

```ts title='Example'
type Obj = { a: string } | { a: string | boolean } | { a: null };

type R1 = Extract<Obj, { a: string | boolean }>; // { a: string } | { a: string | boolean }
type R2 = ExtractByExactValue<Obj, { a: string | boolean }>; // { a: string | boolean }
```

## get

### Get

```ts
type Get<T, K> = ...
```

An alias for `Obj['Key']`.

```ts title='Example'
type R1 = Get<{ a: 1; b: 2 }, "a">; // 1
```

### Set

```ts
type Set<T, K, V> = ...
```

Set a value in an object.

```ts title='Example'
type R1 = Set<{ readonly c?: 1 }, "c", 4>; // { readonly c?: 4 }

type R2 = Set<{ a: 1 }, "b", 2>; // { a: 1, b: 2 }
```

<Callout type='info'>

If the key doesn't exist, it will be added.

</Callout>

### GetDeep

```ts
type GetDeep<T, K, O> = ...
```

Get a deeply nested value using dot-notation.

```ts title='Example'
type Obj = { a: { b?: { c: 1 } } };

type R1 = GetDeep<Obj, "a.b.c">; // 1
type R2 = GetDeep<Obj, "a.b.c", true>; // 1 | undefined
```

<Callout type='info'>

Set `O` to `true` to preserve `undefined` if one of the parents is optional.

</Callout>

### SetDeep

```ts
type SetDeep<T, K, V> = ...
```

Set a deeply nested value using dot-notation.

```ts title='Example'
type R1 = SetDeep<{ a: { b: { c: 1 } } }, "a.b.c", 4>; // { a: { b: { c: 4 } } }

type R2 = SetDeep<{}, "a.b.c", 4>; // { a: { b: { c: 4 } } }
type R3 = SetDeep<{ a: boolean }, "a.b.c", 4>; // { a: boolean }
```

<Callout type='info'>

- If a parent key doesn't exist, it will be created as an empty object.
- If a parent key is not an object type, it won't be modified.

</Callout>

### KeysDeep

```ts
type KeysDeep<T, R, _K> = ...
```

A deep version of [Keys](#keys).

```ts title='Example'
type Config = { foo: string; bar: { baz: number } };

type R1 = KeysDeep<Config>; // "foo" | "bar" | "bar.baz"
type R2 = KeysDeep<Config, "leaf">; // "foo" | "bar.baz"
type R3 = KeysDeep<Config, "parent">; // "bar"
```

<Callout type='info'>

`R` controls whether to return leaf keys, parent keys, or both (default).

</Callout>

## merge

### MergeUnion

```ts
type MergeUnion<A, B, P> = ...
```

Merge two objects, keeping all keys from both. On conflict, `B` wins.

```ts title='Example'
type A = { readonly a: 1; b: 2 };
type B = { a: "<>"; c: 4 };

type AB1 = MergeUnion<A, B>; // { a: "<>", b: 2, c: 4 }
type AB2 = MergeUnion<A, B, true>; // { readonly a: "<>", b: 2, c: 4 }
```

<Callout type='info'>

Set `P` to true to use `A`'s modifiers.

</Callout>

### MergeUnionDeep

```ts
type MergeUnionDeep<A, B, P> = ...
```

Merge two objects deeply, keeping all keys from both. On conflict, values are recursively merged if both are objects, otherwise `B` wins.

```ts title='Example'
type A = { readonly a: 1; b: { c: 1; d: "b" } };
type B = { a: 99; b: { c: 4 } };

type AB1 = MergeUnion<A, B>; // { a: 99, b: { c: 4 } }
type AB2 = MergeUnionDeep<A, B>; // { a: 99, b: { c: 4, d: "b" } }
```

<Callout type='info'>

- Set `P` to true to use `A`'s modifiers.
- Non-object members of `A` are discarded while those of `B` are preserved.

</Callout>

### MergePatch

```ts
type MergePatch<A, B, P> = ...
```

Merge two objects, keeping all keys from `A`. On conflict, `B` wins.

```ts title='Example'
type A = { readonly a: 1; b: 2 };
type B = { a: "<>"; extra: "ignored" };

type AB1 = MergePatch<A, B>; // { a: "<>", b: 2 }
type AB2 = MergePatch<A, B, true>; // { readonly a: "<>", b: 2 }
```

<Callout type='info'>

Set `P` to true to use `A`'s modifiers.

</Callout>

### MergePatchDeep

```ts
type MergePatchDeep<A, B, P> = ...
```

Merge two objects deeply, keeping all keys from `A`. On conflict, values are recursively merged if both are objects, otherwise `B` wins.

```ts title='Example'
type A = { a: 1; b: { c: 1; d: "b" } };
type B = { a: 99; extra: "key"; b: { c: 4; extra: "key" } };

type AB1 = MergePatch<A, B>; // { a: 99, b: { c: 4, extra: "key" } }
type AB2 = MergePatchDeep<A, B>; // { a: 99, b: { c: 4, d: "b" } }
```

<Callout type='info'>

- Set `P` to true to use `A`'s modifiers.
- Non-object members of `A` are discarded while those of `B` are preserved.

</Callout>

### MergeInt

```ts
type MergeInt<A, B, P> = ...
```

Merge two objects, keeping all keys from `A` that exist in `B`. Values are taken from `B`.

```ts title='Example'
type A = { readonly a: 1; b: 2 };
type B = { a: "<>"; c: 4 };

type AB1 = MergeInt<A, B>; // { a: "<>" }
type AB2 = MergeInt<A, B, true>; // { readonly a: "<>" }
```

<Callout type='info'>

Set `P` to true to use `A`'s modifiers.

</Callout>

### MergeIntDeep

```ts
type MergeIntDeep<A, B, P> = ...
```

Merge two objects deeply, keeping all keys from `A` that exist in `B`. Values are recursively merged if both are objects, otherwise they are taken from `B`.

```ts title='Example'
type A = { a: 1; b: { c: 1; d: "b" } };
type B = { a: 9; b: { c: 4 } };

type AB1 = MergeInt<A, B>; // { a: 9, b: { c: 4 } }
type AB2 = MergeIntDeep<A, B>; // { a: 9, b: { c: 4, d: "b" } }
```

<Callout type='info'>

- Set `P` to true to use `A`'s modifiers.
- Non-object members of `A` are discarded while those of `B` are preserved.

</Callout>

### MergeDiff

```ts
type MergeDiff<A, B> = ...
```

Merge two objects, keeping all keys that exist only in `A`.

```ts title='Example'
type A = { readonly a: 1; b: 2 };
type B = { a: "<>"; c: 4 };

type AB = MergeDiff<A, B>; // { b: 2 }
type BA = MergeDiff<B, A>; // { c: 4 }
```

### MergeDiffDeep

```ts
type MergeDiffDeep<A, B> = ...
```

Merge two objects deeply, keeping all keys that exist only in `A` and recursively merging keys that exist in both when both values are objects.

```ts title='Example'
type A = { a: 1; b: { c: 1; d: "b" } };
type B = { b: { d: "b" } };

type AB1 = MergeDiff<A, B>; // { a: 1 }
type AB2 = MergeDiffDeep<A, B>; // { a: 1, b: { c: 1 } }
```

### MergeSymDiff

```ts
type MergeSymDiff<A, B> = ...
```

Merge two objects, keeping all non-shared keys.

```ts title='Example'
type A = { readonly a: 1; b: 2 };
type B = { a: "<>"; c: 4 };

type AB = MergeSymDiff<A, B>; // { b: 2, c: 4 }
type BA = AB;
```

### MergeSymDiffDeep

```ts
type MergeSymDiffDeep<A, B> = ...
```

Merge two objects deeply, keeping all non-shared keys and recursively merges shared keys when both are objects.

```ts title='Example'
type A = { a: 1; b: { c: 1; d: "b" } };
type B = { b: { d: "b" } };

type AB1 = MergeDiff<A, B>; // { a: 1 }
type AB2 = MergeDiffDeep<A, B>; // { a: 1, b: { c: 1 } }
```

## pick

### LoosePick

```ts
type LoosePick<T, K> = ...
```

A distributive/loose version of the built-in [Pick](https://www.typescriptlang.org/docs/handbook/utility-types.html#picktype-keys).

```ts title='Example'
type R1 = Pick<{ a: 1 }, "a" | "b">; // { a: 1, b: unknown }
type R2 = LoosePick<{ a: 1 }, "a" | "b">; // { a: 1 }
```

### StrictPick

```ts
type StrictPick<T, K> = ...
```

A distributive version of the built-in [Pick](https://www.typescriptlang.org/docs/handbook/utility-types.html#picktype-keys).

```ts title='Example'
type R1 = Pick<{ a: 1 } | { b: 2 }, "a">; // { a: unknown } // + Error
type R2 = StrictPick<{ a: 1 } | { b: 2 }, "a">; // { a: 1 } | {}
```

### LooseOmit

```ts
type LooseOmit<T, K> = ...
```

A distributive version of the built-in [Omit](https://www.typescriptlang.org/docs/handbook/utility-types.html#omittype-keys).

```ts title='Example'
type R1 = Omit<{ a: 1; b: 2 }, "a">; // { b: 2 }
type R2 = LooseOmit<{ a: 1; b: 2 }, "a">; // { b: 2 } // + Auto-completion for 'a'

type R3 = Omit<{ a: 1 } | { b: 2 }, "a">; // {}
type R4 = LooseOmit<{ a: 1 } | { b: 2 }, "a">; // {} | {b: 2}
```

### StrictOmit

```ts
type StrictOmit<T, K> = ...
```

A distributive/strict version of the built-in [Omit](https://www.typescriptlang.org/docs/handbook/utility-types.html#omittype-keys).

```ts title='Example'
type R1 = Omit<{ a: 1 }, "z">; // {a: 1}
type R2 = StrictOmit<{ a: 1 }, "z">; // {a: 1} // + Error saying 'z' is not an existing key

type R3 = Omit<{ a: 1 } | { b: 2 }, "a">; // {} // + Error
type R4 = StrictOmit<{ a: 1 } | { b: 2 }, "a">; // {} | {b: 2}
```

## rename

### RenameKey

```ts
type RenameKey<T, K, N> = ...
```

Renames a key of `T`.

```ts title='Example'
type R1 = RenameKey<{ rgb: RGB; a: number }, "a", "alpha">; // { rgb: RGB, alpha: number }
```

### RenameKeys

```ts
type RenameKeys<T, M> = ...
```

Renames multiple keys of `T` using a key-to-new-key object.

```ts title='Example'
type R1 = RenameKeys<{ f: string; b: string; c: 4 }, { f: "foo"; b: "bar" }>; // { foo: string, bar: string, c: 4 }
```
