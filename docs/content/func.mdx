## utils

### Func

```ts tab='Shape'
type Func<A extends ROList = any[], R = any>
```

```ts tab='Source'
type Func<A extends ROList = any[], R = any> = (...args: A) => R;
```

Creates a function type with the given arguments and return type.

```ts title='Example'
type F1 = Func; // () => any
type F2 = Func<[string]>; // (args_0: string) => any
type F3 = Func<[], string>; // () => string
type F4 = Func<[name: string], string>; // (name: string) => string
```

### Param

```ts tab='Shape'
type Param<F extends Func, I extends number>
```

```ts tab='Source'
type Param<F extends Func, I extends number> = Params<F>[NormalizeIndex<I, Params<F>>];
```

Gets the parameter at the given index. Negative indices are supported.

```ts title='Example'
type Fn = (a: string, b: number) => void;
type R1 = Param<Fn, 0>; // string
type R2 = Param<Fn, -1>; // number
```
