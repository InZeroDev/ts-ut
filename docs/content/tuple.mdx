## push

### Push

```ts tab='Shape'
type Push<T extends ROList, E, S extends boolean = false>
```

```ts tab='Source'
type Push<T extends ROList, E, S extends boolean = false> = [
	...Required<T>,
	...(IsSubtype<S, true> | IsSubtype<E, ROList> extends true ? Extract<E, ROList> : [E]),
] extends infer Result extends ROList
	? MatchTuple<Result, T>
	: never;
```

Pushes an element to the end of a tuple.

```ts title='Example'
type R1 = Push<[1, 2, 3], 4>; // [1, 2, 3, 4]
type R2 = Push<[1, 2, 3?], 4>; // [1, 2, 3?, 4?]
```

<Callout type='info'>

The tuple's shape is preserved.

</Callout>

### Pop

```ts tab='Shape'
type Pop<T extends ROList, N extends number = 1>
```

```ts tab='Source'
type Pop<T extends ROList, N extends number = 1> =
	Required<T> extends readonly [...infer Head extends ROList, ...Tuple<N>]
		? MatchTuple<Head, T>
		: [];
```

Pops an element from the end of a tuple.

```ts title='Example'
type R1 = Pop<[1, 2, 3]>; // [1, 2]
type R2 = Pop<[1, 2, 3?]>; // [1, 2]
```

### Unshift

```ts tab='Shape'
type Unshift<T extends ROList, E, S extends boolean = false>
```

```ts tab='Source'
type Unshift<T extends ROList, E, S extends boolean = false> = [
	...(IsSubtype<S, true> | IsSubtype<E, ROList> extends true ? Extract<E, ROList> : [E]),
	...Required<T>,
] extends infer Result extends ROList
	? MatchTuple<
			Result,
			T,
			IsSubtype<S, true> | IsTuple<E> extends true ? Extract<E, ROList>["length"] : 1
		>
	: never;
```

Adds an element to the beginning of a tuple.

```ts title='Example'
type R1 = Unshift<[1, 2, 3], 4>; // [4, 1, 2, 3]
type R2 = Unshift<[1, 2, 3?], 4>; // [4, 1, 2, 3?]
```

### Shift

```ts tab='Shape'
type Shift<T extends ROList, N extends number = 1>
```

```ts tab='Source'
type Shift<T extends ROList, N extends number = 1> =
	Required<T> extends readonly [...Tuple<N>, ...infer Rest extends ROList]
		? MatchTuple<Rest, T, NegAbs<N>>
		: [];
```

Removes an element from the beginning of a tuple.

```ts title='Example'
type R1 = Shift<[1, 2, 3]>; // [2, 3]
type R2 = Shift<[1, 2, 3?]>; // [2, 3?]
```

## utils

### Tuple

```ts tab='Shape'
type Tuple<L extends number, T = unknown>
```

```ts tab='Source'
type Tuple<L extends number, T = unknown> = L extends L ? _Tuple<L, T> : never;
```

Creates a tuple of the given length and parameter type.

```ts title='Example'
type R1 = Tuple<1>; // [unknown]
type RGB = Tuple<3, number>; // [number, number, number]
```

### ROTuple

```ts tab='Shape'
type ROTuple<L extends number = -1, T = unknown>
```

```ts tab='Source'
type ROTuple<L extends number = -1, T = unknown> = Readonly<Tuple<L, T>>;
```

A readonly version of [Tuple](#tuple).

### NonEmptyTuple

```ts tab='Shape'
type NonEmptyTuple<T = unknown, L extends number = 1>
```

```ts tab='Source'
type NonEmptyTuple<T = unknown, L extends number = 1> = [...Tuple<L, T>, ...T[]];
```

A tuple with at least `L` elements.

```ts title='Example'
type R1 = NonEmptyTuple; // [unknown, ...unknown[]]
type R2 = NonEmptyTuple<number>; // [number, ...number[]]
type R3 = NonEmptyTuple<number, 2>; // [number, number, ...number[]]
```

### NonEmptyROTuple

```ts tab='Shape'
type NonEmptyROTuple<T = unknown, L extends number = 1>
```

```ts tab='Source'
type NonEmptyROTuple<T = unknown, L extends number = 1> = [
	...ROTuple<L, T>,
	...(readonly T[]),
];
```

A readonly version of [NonEmptyTuple](#nonemptytuple).

### KeyofTuple

```ts tab='Shape'
type KeyofTuple<T extends readonly unknown[]>
```

```ts tab='Source'
type KeyofTuple<T extends readonly unknown[]> = Exclude<keyof T, keyof any[]>;
```

Returns the indexes of a tuple.

```ts title='Example'
type R1 = KeyofTuple<[1, 2, 3]>; // "0" | "1" | "2"
```

### KnownTuple

```ts tab='Shape'
type KnownTuple<T extends ROList>
```

```ts tab='Source'
type KnownTuple<T extends ROList> = T extends readonly [infer F, ...infer R]
	? [F, ...KnownTuple<R>]
	: [];
```

Returns the guaranteed elements of a tuple.

```ts title='Example'
type R1 = KnownTuple<[number, number, ...number[]]>; // [number, number]
```
