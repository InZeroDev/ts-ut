## List

```ts
type List<T> = ...
```

An alias for `T[]`.

## ROList

```ts
type ROList<T> = ...
```

An alias for `readonly T[]`.

## OrList

```ts
type OrList<T> = ...
```

An alias for `T | T[]`.

## OrROList

```ts
type OrROList<T> = ...
```

An alias for `T | readonly T[]`.
